# gitorio documentation

> Every document in this repository, one line each — start with the root README, and see AGENTS.md for how to work here.

**Backlog of record:** [`BACKLOG.md`](../BACKLOG.md), the append-only file backlog declared in `.github/sdlc.yml`.

This index covers the root documents of record and everything under `docs/`. The other prose lives elsewhere by design ([`DOCUMENTATION-MAP.md`](DOCUMENTATION-MAP.md) explains the split): the user-facing guides in [`_docs/`](../_docs/) are rendered in the app's Docs tab, spec packages are in [`specs/`](../specs/README.md), session-log drafts in [`blog/`](../blog/README.md), the closed bootstrap prompts in [`seeds/`](../seeds/README.md), the gate scripts in [`tools/`](../tools/README.md), the Claude Code tooling in [`.claude/`](../.claude/README.md), and the two imported projects under `packages/` keep their own docs.
