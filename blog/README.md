# Session logs → it-journey

> The staging area for `/session-log` drafts on their way to the it-journey repo.

Every Claude Code session on this repo ends with a draft post in `blog/drafts/` (see the `/session-log` command and AGENTS.md golden rule #10). Drafts use `draft: true` frontmatter and include a **Working-with-AI tip** section, then get reviewed and moved to the `it-journey` repo for publishing.
